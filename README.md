# Rock, Paper, Scissors Game 🎮

This is a simple **Rock, Paper, Scissors** game built using **HTML, JavaScript, and the browser prompt**. The game lets you play **5 rounds** against the computer, and at the end, it announces the winner based on the scores.

## 🚀 How to Play
1. Open the game in a browser.
2. Enter your choice (**Rock, Paper, or Scissors**) when prompted.
3. The computer will randomly select its move.
4. The round winner will be displayed in the console.
5. After 5 rounds, the final winner is declared.

## 🛠️ Technologies Used
- HTML
- JavaScript (ES6)
- Browser Console

## 📜 Game Rules
- **Rock beats Scissors** 🪨✂️
- **Scissors beats Paper** ✂️📄
- **Paper beats Rock** 📄🪨
- If both players choose the same move, it's a **tie**.

## 📌 Features
✅ Validates user input (only accepts Rock, Paper, or Scissors)  
✅ Keeps track of **player** and **computer** scores  
✅ Displays round-by-round results in the **console**  
✅ Announces the final winner after 5 rounds
